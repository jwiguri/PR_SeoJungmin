# 서정민 Game Designer Portfolio

게임 기획자로서의 자기소개와 기획 포트폴리오, 프로젝트 및 대외활동 경험을 한곳에 정리한 인터랙티브 자기 PR 웹페이지입니다. 페이지를 직접 기획·구성하고 AI를 활용해 웹으로 구현했으며, 각 메뉴에서 기획서 원문과 프로젝트별 담당 업무 및 제작 과정을 확인할 수 있습니다.

## 웹페이지 미리 보기

전체 파일을 내려받은 뒤 [`index.html`](./index.html) 파일을 클릭하면 웹페이지를 미리 볼 수 있습니다.
